# Does it Matter? — Poker Tracker
A small browser app for tracking poker results and which hands mattered. No installation or dependencies required.
## Launch
Download this folder and open `index.html` in your browser. Keep `app.js` next to it.
## Features
- Coinflip wins and losses
- Tuuritin (I got lucky): wins
- Mut tuuritettiin (opponent got lucky): losses
- Manual Did it matter? Yes/No for each hand, including bounty impact
- Category totals, win rate, optional notes, and recent history
- Undo the most recent hand
- Download and restore JSON backups
## Data
Records are saved only in this browser on this device using localStorage. Other browsers, devices, and website addresses have separate records. Download backups to keep a copy or transfer records. Clearing browser storage removes local records.
This repository contains application code only. Do not commit hand records, backups, credentials, or personal information.
